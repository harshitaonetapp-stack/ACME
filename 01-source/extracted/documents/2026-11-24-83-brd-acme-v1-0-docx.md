Business Requirements Document
ACME Courier Portal — daily report export · Version 1.0 · 24 November 2026 · Prepared by OneApp
1. Background
Operations staff read a daily report each morning showing how many pickups were booked, assigned, completed and cancelled for the previous day. The report is produced as plain text.
ACME's finance team uses those figures for monthly client billing. Because the report is text only, somebody re-types the numbers into a spreadsheet by hand each morning. ACME report that this takes around twenty minutes a day and that transcription mistakes have twice led to a client being invoiced the wrong amount.
2. Scope
This document covers making the existing daily operations report available in a form that finance can load directly into a spreadsheet, without re-typing.
It does not cover changing what the report counts, how the figures are calculated, or how finance use them afterwards.
3. Requirements
The daily operations report can be produced as a CSV file for a given day, in addition to the existing plain-text version.
The CSV contains one row per pickup status, with the status and its count.
The figures in the CSV match the figures in the text report for the same day.
The CSV includes a header row, so finance can see what each column holds without being told.
The file opens cleanly in the spreadsheet software finance already use.
4. Out of scope
Emailing or scheduling the report. Staff will continue to produce it when they need it.
Removing or replacing the plain-text report, which operations staff still read on screen.
Any change to how pickups are counted or which day they belong to.
5. Notes
Raised by Priya (ACME operations) on the weekly call of 17 November 2026, on behalf of ACME finance. Priya has asked to see the output before it goes to her finance team.
